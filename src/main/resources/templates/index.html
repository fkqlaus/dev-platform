Git 서버 연결 설정 확인 중

이미 clone·push·pull에 사용하는 SSH Git 서버를 연결합니다. 서버에 별도 파일을 설치하지 않습니다.

1. 기존 Git 주소

절대 경로의 SSH 주소를 지원합니다. HTTPS·GitLab/Gitea API 연결은 지원하지 않습니다.

2. 생성에 사용할 계정

그룹을 지정하면 생성 계정이 그 그룹에 속해야 합니다. 기존 서버의 소유자·권한은 변경하지 않습니다.

3. 서버 키 확인


                
                
            

            
키 조회에는 비밀번호를 보내지 않습니다. 승인한 키를 플랫폼이 저장하므로 known_hosts 파일을 직접 준비할 필요가 없습니다.

            
4. 검사하고 저장

            
설정은 이 PC의 config/connection.properties에 비밀번호를 포함한 평문으로 저장됩니다. 공유하거나 Git에 올리지 마세요. 저장한 연결은 기존 파일 설정보다 우선합니다.

접속 주소는 생성 결과입니다. 실제 clone·push 성공 여부는 개발 PC에서 확인하세요.

        
새로 시작하기

        
개발 PC에서 프로젝트를 둘 상위 폴더의 터미널을 열고 실행하세요.

        

        
기존 로컬 프로젝트 연결하기

        
개발 PC의 기존 프로젝트 폴더에서 먼저 상태를 확인하세요.

        
git status
git remote -v

        
Git 저장소가 아니라면 git init으로 초기화하세요. 기존 origin이 없을 때만 다음 명령을 실행하세요.

        

        
기존 origin을 유지하려면 사용하지 않는 별도 이름으로 추가할 수 있습니다.

        

        
첫 push 전에는 .gitignore와 커밋할 파일을 검토하고 필요한 파일만 커밋하세요. 서버 비밀번호나 개인키를 포함하지 마세요.

        
git branch --show-current
git push -u origin HEAD

        
위 push는 브랜치에 첫 커밋이 있고 origin을 새 저장소로 연결한 경우에 사용하세요. 별도 이름을 사용했다면 origin을 그 이름으로 바꾸세요.
